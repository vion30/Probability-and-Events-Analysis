
# Probability and Events Analysis


## Overview

This repository contains a collection of Jupyter Notebooks demonstrating the application of probability theory and event analysis in various scenarios. The purpose of this project is to illustrate the concepts of probability, events, and their intersections through practical examples involving cards, dice, coins, and real-world datasets like Airbnb room availability.
## Key Features

Basics of Probability

Understanding sample spaces, events, and probabilities.
Calculating probabilities of simple and compound events using a deck of cards.

Working with Events

Analyzing room availability probabilities in cities using Airbnb data.
Exploring mutually exclusive and joint events.
Applying probability rules like addition and multiplication to real-world data.

DIY Probability Challenges

Solving custom problems using coins, dice, and cards.
Calculating probabilities for various scenarios:
Rolling dice.
Flipping coins.
Drawing cards.
## Technology Used

- Programming Language: Python
- Libraries:
  pandas for data manipulation.
  numpy for numerical computations.



## Installation

Clone the repository:
```
git clone https://github.com/your-username/probability-events.git
cd probability-events
```

Install dependencies:
```
pip install pandas numpy
```
## Run

Launch Jupyter Notebook:
```
jupyter notebook
```
Open any notebook from the repository (e.g., Demo_Basics_of_Probability.ipynb) and run the cells.
